# TPS Shooter

## Описание

Игровой прототип TPS-шутера на Unity.

Игрок проходит игровой уровень, сражается с врагами, использует оружие,
собирает предметы, получает ключ, открывает дверь и достигает конечной точки уровня.

## Unity

- Unity 2022.3.62f3
- Universal Render Pipeline (URP)
- Input System
- Cinemachine
- TextMeshPro
- AI Navigation
- Zenject (Extenject)
- DOTween
- UniTask

## Архитектура и паттерны

| Паттерн | Реализация |
|---|---|
| State Machine | EnemyPatrolState, EnemyCombatState, EnemyTakeCoverState, EnemyAlertState |
| Factory | Фабрики создания игровых объектов |

| Dependency Injection | Zenject, ProjectContext, SceneContext |

Основные зависимости:

- IInputService
- PlayerController

- фабрики игровых объектов

Используются:

- ProjectContext
- SceneContext

## Игровой цикл

1. Запуск игровой сцены.
2. Передвижение по уровню.
3. Сражение с врагами.
4. Сбор боеприпасов.
5. Получение ключа.
6. Открытие двери.
7. Достижение конечной точки.
8. Победа.
9. Переход в Menu.

## Смерть и респавн

При получении смертельного урона:

1. Здоровье игрока становится равным нулю.
2. Появляется сообщение «ВЫ ПОГИБЛИ».
3. Управление игроком временно отключается.
4. Через небольшую задержку игрок перемещается на Spawn Point.
5. Здоровье восстанавливается.
6. Сообщение о смерти исчезает.
7. Управление игроком возвращается.

## Оружие

В проекте используется пять оружий.

Оружие выбирается цифровыми клавишами:

- 1 — оружие 1
- 2 — оружие 2
- 3 — оружие 3
- 4 — оружие 4
- 5 — оружие 5

Для оружия используется базовый класс `WeaponBase`
и конфигурации `WeaponConfig`.

## Подбор предметов

В игре реализована система подбора предметов.

Доступные предметы:

- Боеприпасы
- Ключ

Взаимодействие с предметами выполняется клавишей E.

## Двери

Дверь открывается при взаимодействии с игроком.

Для открытия запертой двери требуется ключ.

Анимация открытия двери выполняется с использованием DOTween.

## Враги

В игре реализовано два типа поведения врагов.

Используются:

- NavMeshAgent
- Field of View
- State Machine
- патрулирование
- обнаружение игрока
- боевое состояние
- стрельба
- потеря цели
- поиск укрытия
- смерть врага

Враг прекращает атаку после смерти и при потере цели.

## Конец игры

При достижении конечной точки уровня игрок побеждает.

После победы выполняется переход в сцену `Menu`.

## Сцены

Необходимые сцены должны быть добавлены в Build Settings.

Используются:

- Menu
- игровая сцена
